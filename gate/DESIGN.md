# GATE VADER 仕様メモ

決まったことをここに残す。実装はこの内容に合わせる。変えるときはここも直す。

> **絶対の方針：墨絵の世界観を崩さない。** 見た目はすべて 墨絵 ＋ 和紙 ＋ 巻物（掛軸・絵巻）。色は 墨・うす墨・朱・藍 だけ。
> 新しいキャラ・敵・画面・UI・イベントも必ずこの世界観で作る（ネオン・ピクセル・デフォルメの強いアニメ調・3D風は使わない）。

## 名前・表記
- 名前は **GATE VADER**（タイトルだけ英語）。フォルダは `game/gate/`。
- それ以外の文言は **日本語 / English を切り替え**（タイトル画面のボタン。初期値はブラウザの言語）。
- **主人公はワニ**。左から流れてくる**魚を撃って食べる**。ボスは海の妖怪と大きな生き物。
- 数の単位：日本語では 万・億・兆・京… で表す（英語は K/M/B…）。段の名前は「第〇段」。

## 見た目：墨絵の巻物（v0.16〜）
- 絵はすべて `ink.js` がコードで描く SVG（筆のかすれ・墨のにじみをフィルタで出す）。色は **墨・うす墨・朱・藍** だけ。背景は**和紙**。
- 子ども向けのデフォルメはしない（対象は十代〜大人のカジュアル層）。
- 文字は筆の書体（Yuji Boku / Yuji Syuku、予備に Noto Serif JP）。タイトル **GATE VADER** の横に朱の落款「鰐」。
- **主人公ワニ**：上から見た墨絵。歩き4コマ、表情 ふつう / 喜ぶ / 痛がる。仲間は同じ絵を小さく。スキンは墨の色（下の伝統色）。
- **魚**：泳ぐ4コマ。朱の魚は「食べると銭」の段で出る。
- **ボス10種**（第一段〜第十段で毎回ちがう）：大河豚 / 大水母 / 大蛸 / 蟹坊主 / 梶木 / 大烏賊 / 大鰻 / 磯撫で / 赤えい / **海坊主（大ボス）**。撃たれると痛がり、倒すと沈む。

### 日本の文化を誤解させないための決まり
- **縦画面は掛軸**に見立てる（上に八双の竹、下に軸木）。**絵巻は横長で右から左へ読む**ものなので、段の始めに出す横長の札だけを絵巻にし、文字は**縦書き・右の列から**・漢数字で書く（括弧や算用数字は縦書きに入れない）。
- ゲートは**短冊（ただの紙の札）**。神社のお札・護符には見せない（神紋・梵字・朱印風の文様は使わない）。
- ボスは実在の伝承にいる**海の妖怪**（蟹坊主・磯撫で・赤えい・海坊主）と大きな生き物だけ。**神さま・神聖な存在（竜神・乙姫など）は敵にしない**。
- 妖怪の出どころの説明を書くときは、伝わる地域や書物をまちがえない（蟹坊主＝寺の怪談、磯撫で＝西日本の海の怪、赤えい＝島と見まちがえる大魚、海坊主＝各地の海に伝わる黒い大入道）。
- ワニを「日本の伝統の生き物」としては描かない（古事記の「和邇」はサメのこととする説が有力なため、結びつけない）。
- スキンの色名は実在の**伝統色名**（墨・松葉色・藍色・臙脂・金茶・銀鼠・江戸紫・朱色・漆黒・青磁色）。
- 武器名は映画などの作品名を使わない（和の言葉：豆鉄砲・双筆・扇・早打ち・跳ね墨・波筆・散らし墨・追い墨・一筆・三叉銛・大顎）。
- 通貨は **銭**（コイン）と **真珠**（ガチャ用）。命＝ライフ、腹＝飢え、札＝ゲート、餌＝魚。

## タイトル・ホーム画面（v0.18〜。参考：スマホRPGのホーム ＋ ちいぽけのタイトル）
- **タイトル**：起動画面のあと毎回。絵巻の一場面（遠くに海坊主の影・波・魚・流れる短冊・3匹のワニ）の上に GATE VADER と落款、下に「タップしてはじめる」、左上に版、右上に ≡（設定へ）、下に © MASU01。
- **ホーム**（スマホRPGの定番配置）
  - 上：左に自分（ワニの顔・段位の朱札・「第〇段 突破」・最高米）、右に 銭 / 真珠 と ＋（ためかたを表示）。
  - 上の真ん中：十段の道のり。
  - 左の列：お知らせ / 道のり（初突破の真珠の一覧）/ 遊び方。右の列：ガチャ / 墨の色 / 絵巻。新しいものには朱の点。
  - まん中：装備中のワニ（歩く。さわると喜んでひとこと）と、武器・墨の色の札。背景は薄い海坊主・波・魚。
  - 下の角：左に大きな朱の丸「出陣」（続きがあれば「続きから」、上に小さく「はじめから」）、右に墨の丸「強化」。間にめくれるバナー（次の初突破・ガチャ天井・強化できる・絵巻）。
- **下のタブ**：装備 / ガチャ / ［ホーム］ / 絵巻 / 設定。真ん中だけ大きな丸。左右スワイプでも移れる。
- 装備・ガチャ・絵巻（記録）・設定の各画面は v0.17 の形。一時停止・結果・遊び方・お知らせ・道のりは掛軸のカード。
- 英語のときは筆の英字を使わず明朝の太字。筆書体の数字もくずれるので、数字・英字を含む文字は楷書寄り（Yuji Syuku）。
- アイコン：和紙の上に墨のワニ（上半身を大きく）と朱の落款「鰐」。

## 画面（縦）
- 左半分＝**魚の大群**（小さく・大量に。食べている感を出す）。右半分＝**迫ってくるゲートとアイテム**。
- 自機は下で**左右に動く**（ドラッグした量だけ動く。指で自機が隠れない）。狙いをつける操作はない。
- 弾は**まっすぐ上**に飛ぶ。どちらのレーンに立つか（食べるか、ゲートを育てるか）が駆け引き。
- 仲間は自機の左右に並んで一緒に撃つ。**上限なし**。見えるのは前の列7（自分を入れて）＋後ろの列8。それより多い分は見えないが「段数」として弾に乗る（足元に「後ろに仲間 +N（段数に）」と出す）。
- 横画面（未実装）：縦画面を倒した形。対比は上下、進行は左か右。

## ゲート（右）
- 上からこちらへ迫ってくる。**撃つと数値が良い方向に動く**（マイナスも撃ち続ければプラスに転じる）。
- **自分がくぐった時だけ効果が確定**（Count Masters / Weapon Craft Run と同じ）。くぐらなければ何も起きない。対象は DMG（ダメージ）・LINE（段数）・CREW（撃つ人数）。
- 狙いをつける操作・狙いの線・照準は**なし**。
- 種類：＋ / − / × / ÷。
- **LIFE ゲート**（ハート+1）はたまにだけ出る（HEAL アイテムと合わせて、距離で3〜5分に1回ほど）。
- ゲートは**1列に1つ**（2つ同時には取れない）。
- 数値は**弾1発で1**だけ良い方向に動く（×は0.01）。難しさは初期値で決める（終盤ほど -100 のような深いマイナスが増える）。
- 種類：威力（DMG）・連射（RATE）・段数（LINE）・仲間（CREW）の ＋/− と、たまに × / ÷。
- **武器の札**（たまにだけ）：**今の武器はそのまま**で、札の撃ち方が自分の**外側に左右1本ずつ（計2本）加わる**。同じ札を重ねると外にもう2本（1種類3段まで）。撃つと中身の撃ち方が切り替わる。
  - 中身：拡散 / 反射 / 波打ち / 追尾 / 散弾 / 貫通 / 一閃（今の武器と同じ撃ち方は出ない）
- 未実装：ボーナスコイン。
- 表示と実際にかかる値は必ず一致させる（LINE・CREW は整数で効く）。

## アイテム（右）
- CREW / POWER（未実装：強い助っ人）。HEAL はたまにだけ。**壊さないと手に入らない**。壊さずに**ぶつかったら**「当たった」扱い（避けてもいい）。

## ハートと餓死
- **ハートは1つ**で始まる（最大3）。増えるのは LIFE ゲートと HEAL だけ。時間やボス撃破では回復しない。
- **当たったら負け**：壊せなかったアイテムが届く／ボスが届く。ハートが残っていれば1つ減って続行（直後は少し無敵）。
- **飢餓ゲージ（「腹」、左上）**：魚を1匹逃すと-1、1匹食べると少し戻る。10匹ぶんの目盛りが尽きたら**餓死**。

## 魚（左）
- モブにHPはない（一撃で食べられる）。強い弾は何匹も貫く（上限あり）。
- ボスだけHPを持ち、HPバーは頭の上。

## 進行：ステージ制（シームレス）
- **本編は 10 ステージ**（6分前後）。1ステージは道のり（約24秒）＋最後に**ボス**。ステージ10は大ボス。止まらずに次へ。
- **速さ**：ステージ1→10で**2倍**まで上がり、その先は**上限（2.6倍）**で止まる。
- **ステージごとに変化**（繰り返しの中に毎回ちがうルール）：朱の魚（食べると銭）/ ゲートラッシュ / 魚の群れ / 逆流ゲート / 急流 / 夜の海（上が暗い）。本編はやさしい順→きつい順。ステージの始めに名前を出す。
- **ボスは種類ごとに攻撃が決まっている**：大河豚・蟹坊主・大鰻・赤えい＝墨玉 / 大水母＝魚を呼ぶ / 大蛸＝墨を吐く / 梶木・磯撫で＝突進（予告あり）/ 大烏賊＝墨＋呼ぶ / 海坊主＝墨玉＋突進。ステージ1のボスだけは攻撃しない。11 から先は順番にまた出て、攻撃が1つ増える。**当たったら負け**（ライフがあれば1つ減る）。
- ステージ10を倒すと GAME CLEAR、止めずに **∞ COIN RUSH** へ：クリアするたびにコインが **1.35倍ずつ雪だるま式**に増える腕前勝負。
- 左上のバーはそのステージの進み具合（道のり 75% ＋ ボス 25%）。横に「ステージ n/10」、右上にそのステージの変化。

## 強さの流れ（序盤つらい → 中盤楽しい → 終盤苦しい）
- 最初は **1秒に1発・1列・1人・威力1**（豆鉄砲）。魚も少なめだが、ぎりぎり。
- 連射・段数・仲間の上限は**ステージが進むと少しずつ開く**（ステージ8で全開）。1枚のゲートで +3 まで。
- 終盤は、深いマイナスゲートと速さで苦しくなる。
- 初回はすぐ負けてよい（コインで強化し、初回クリアのパールで武器を増やして、遠くへ行けるようになる）。

## 銭・真珠・装備・ガチャ（v0.19〜）
- 通貨は2つ。**銭＝強化用**、**真珠＝ガチャ用**。
- 銭：旅が終わると進んだ距離から換算。武器と墨の色の強化に使う。
- 真珠：**600米ごとに1つ** ＋ 段を**初めて突破**したとき（通常5、第十段は30）。
- ガチャは **1回10真珠 / 10連100真珠（SR以上1つ確定）**。**武器・スキンそれぞれ最初の10連は無料**。確率 SSR 2% / SR 10% / R 28% / N 60%。50回目は SSR 確定（天井）。持っているものは銭に変わる。
- **何が出るか分かるように**：ガチャ画面に「注目」（SSR・SR を絵つきで順に表示。撃ち方・効果・数値）、「ラインナップ」（全部の絵・効果・1つずつの確率）、「集めたもの」（持っていないものも絵を薄く表示）。
- 武器 **21種**（絵は ink.js の墨絵の道具：筆・扇・硯・竹筒・番傘・櫂・投網・凧・太鼓・錨・三叉銛・大顎 など）。コインで強化（最大Lv10、威力×1.35/Lv、3Lvごとに連射+1）。
- スキン **50種**：ワニの墨の色（実在の伝統色名）20種 ＋ **姿が変わる**30種。
  - **色が違うだけのワニはすべて N**。SR・SSR は姿が変わる（生き物・小物）スキンだけ（v0.21〜）。
  - 生き物：鰐・亀・蛙・鯉（緋鯉・金鯉）・蟹・山椒魚・鯰・鮫・兎（鳥獣戯画ふう）・河童（伝承）。神仏・信仰の対象は使わない。
  - 小物：笠・鉢巻・蓑・風呂敷（旅の荷）・羽織。**家紋は描かない**（実在の家の紋と誤解されないように）。
  - 絵は ink.js の critter()（上から見た墨絵、歩き4コマ×ふつう/喜ぶ/痛がる）。レベルで伸びる小さな効果。最大Lv5。

## 贈り物・今日のおまけ・日課（v0.20〜）
- **贈り物**（ホーム左の「贈」）：届いたものを受け取る（1つずつ / まとめて）。はじめての贈り物（真珠50・銭300）、更新のお礼、今日のおまけ。
- **今日のおまけ**：その日はじめてホームに来たとき、7日でひと回りの判子の表を出す（真珠5 / 銭300 / 真珠5 / 銭500 / 真珠10 / 銭800 / 真珠30）。中身は贈り物へ。
- **日課**（ホーム左の「課」）：毎日0時に新しくなる。魚150匹・札15枚・ボス2体・合計1500米。それぞれ真珠5、ぜんぶで真珠10。

## 見た目・負荷
- 弾の本数と弾速は、スマホが熱くならない所まで。見た目の弾数に上限を設け、超えた分は1発の重みに乗せる。
- 軽量モード：重い端末では自動で提案・切替。タイトルで手動切替もできる。

## チュートリアル・遊び方
- 初めてスタートした時だけ、1つずつ実際にやって進むチュートリアル（移動 → 食べる → ゲートを撃つ → 届いて確定 → アイテムを壊す → まとめ）。スキップ可。
- チュートリアル中は飢えず、当たってもライフが減らない。ゲートは早めに届く。
- タイトルの「遊び方」でいつでも説明を読める。

## 起動・流用
- 起動画面は `infinity` と同じ流れ（ロゴ → クレジット → 注意事項）。アイコンだけ差し替え。
- **セーブスロットはなし**（セーブは1つ）。
- PWA・（今後）ランキングは `infinity` から流用してよい。

## 開発用
- `?bot`（自動操縦）・`?ts=10`（倍速）・`?clear=600`（100% までの秒数）は localhost でだけ効く。

## 公開
- `game/gate/` の更新は、確認なしで PR を作って main にマージ（公開）してよい。戻す指示があれば戻す。

## Android版のアカウントと広告
- 設定からGoogleログインと先着テスターコードを登録。テスター権利はサーバーで確認し、登録アカウントに固定する。
- アカウント画面・広告・バックグラウンド中は出陣を一時停止し、戻るとカウントダウンから再開する。既に手動停止していた出陣は勝手に再開しない。
- 通常プレイヤーの広告候補は出陣終了の結果画面のみ。3回の終了・3分以上の間隔を条件にし、開始直後や戦闘中には出さない。広告未取得・通信失敗でも基本プレイは可能。
- 同意画面の読み込みが遅れた場合も、表示直前に同じアカウント・結果画面・フォアグラウンドか再確認する。既に次の出陣へ進んでいたら表示しない。アカウントの切替やテスター登録後は古い広告の読み込み結果を破棄する。
- Android同梱版はService Workerを登録せず、同梱資産を使う。ブラウザ版のPWAは従来どおり。

## Android版のオンライン保存
- 共通オンラインアカウント削除は「無限の次へ」と「GATE VADER」の両方を対象にする。対象データ、取り消し不可、テスター権利の終了を確認し、同じGoogleアカウントで再認証する。削除中はオンライン保存を止め、通信失敗や途中終了を完了とは表示しない。
- この端末の進行を消すかは別の選択にする。共通Firebase認証を使う別サービスに利用記録がある場合、そのサービスの認証情報とデータを残す。Googleアカウント本体は削除しない。本番ルールと画面経路の検証が済むまでは削除を準備中として表示する。
- Googleアカウント単位で銭・真珠・装備・突破記録・贈り物・日課を保存する。出陣途中の状態は端末に残し、クラウドには含めない。
- 端末とクラウドに異なる進行がある場合は選択を待つ。復元前に内容を表示し、現在の端末データを保存してから読み込む。クラウド更新前にも古いクラウドを端末に残し、復元前の確認を行える。
- 自動保存は5分間隔、手動保存も20秒以上あける。サーバーでも更新間隔・データ型・容量・版番号を検証する。無料枠の不足や通信失敗では端末の基本プレイを継続する。
- 別端末が更新した版を上書きしない。保存結果が不明なときは再送せず、サーバーで同じ内容と版を読み取り照合する。
- 保存内容は最大64,000文字、未受取の贈り物200件、贈り物受取履歴2,000件まで。上限に達しても勝手に切り捨てず、オンライン保存を止めて端末の進行を保持する。
- Googleアカウント本人だけが保存内容を読み書きできる。他のアカウントの参照と保存一覧の取得は許可しない。本番接続・実機動作は公開前に別途確認する。

## 結果画面から次の出陣へ
- 結果に装備中の武器の次のレベル・実際の威力・必要な銭または不足分を表示する。次の初突破で得られる真珠も示す。
- 「装備と強化を選ぶ」から装備画面へ移れる。自動購入やガチャ強制は行わず、どの装備に投資するかはプレイヤーが選ぶ。
