# GATE VADER 仕様メモ

決まったことをここに残す。実装はこの内容に合わせる。変えるときはここも直す。

## 名前・表記
- 名前は **GATE VADER**（タイトルだけ英語）。フォルダは `game/gate/`。
- それ以外の文言は **日本語 / English を切り替え**（タイトル画面のボタン。初期値はブラウザの言語）。
- **主人公はワニ**（緑）。左から流れてくる**魚を撃って食べる**。ボスは大きな魚。

## 見た目
- 背景は**海**（深い青のグラデーション・立ちのぼる泡・ゆらぐ光）。自機の下は海底。

## 画面（縦）
- 左半分＝**魚の大群**（小さく・大量に。食べている感を出す）。右半分＝**迫ってくるゲートとアイテム**。
- 自機は下で**左右に動く**（ドラッグした量だけ動く。指で自機が隠れない）。狙いをつける操作はない。
- 弾は**まっすぐ上**に飛ぶ。どちらのレーンに立つか（食べるか、ゲートを育てるか）が駆け引き。
- 仲間（CREW）は自機の左右に並んで一緒に撃つ。
- 横画面（未実装）：縦画面を倒した形。対比は上下、進行は左か右。

## ゲート（右）
- 上からこちらへ迫ってくる。**撃つと数値が良い方向に動く**（マイナスも撃ち続ければプラスに転じる）。
- **自分がくぐった時だけ効果が確定**（Count Masters / Weapon Craft Run と同じ）。くぐらなければ何も起きない。対象は DMG（ダメージ）・LINE（段数）・CREW（撃つ人数）。
- 狙いをつける操作・狙いの線・照準は**なし**。
- 種類：＋ / − / × / ÷。
- **LIFE ゲート**（ハート+1）はたまにだけ出る（HEAL アイテムと合わせて、距離で3〜5分に1回ほど）。
- ゲートは**1列に1つ**（2つ同時には取れない）。
- 数値は**弾1発で1**だけ良い方向に動く（×は0.01）。難しさは初期値で決める（終盤ほど -100 のような深いマイナスが増える）。
- 種類：威力（DMG）・連射（RATE）・段数（LINE）・仲間（CREW）の ＋/− と、たまに × / ÷。
- **WEAPON ゲート**（たまにだけ）：撃つと中身の武器が切り替わり、届いた時の武器になる。
  - NORMAL（まっすぐ）/ SPREAD（扇状）/ BOUNCE（斜めに撃ち壁で反射。両レーンに届く）/ BEAM（1人1本、威力をまとめてよく貫く）
- 未実装：ボーナスコイン。
- 表示と実際にかかる値は必ず一致させる（LINE・CREW は整数で効く）。

## アイテム（右）
- CREW / POWER（未実装：強い助っ人）。HEAL はたまにだけ。**壊さないと手に入らない**。壊さずに**ぶつかったら**「当たった」扱い（避けてもいい）。

## ハートと餓死
- **ハートは1つ**で始まる（最大3）。増えるのは LIFE ゲートと HEAL だけ。時間やボス撃破では回復しない。
- **当たったら負け**：壊せなかったアイテムが届く／ボスが届く。ハートが残っていれば1つ減って続行（直後は少し無敵）。
- **飢餓ゲージ（🍖、左上）**：魚を1匹逃すと-1、1匹食べると少し戻る。10匹ぶんの目盛りが尽きたら**餓死**。

## 魚（左）
- モブにHPはない（一撃で食べられる）。強い弾は何匹も貫く（上限あり）。
- ボスだけHPを持ち、HPバーは頭の上。

## 進行：ステージ制（シームレス）
- **100 ステージ**。1ステージは道のり（約24秒）＋最後に**ボス**。**10 の倍数は大ボス**。止まらずに次のステージへ（「ステージ n クリア！」）。
- 左上のバーはそのステージの進み具合（道のり 75% ＋ ボス 25%）。横にステージ番号。
- 速さはステージごとに上がる（ステージ100で約4倍）。1ステージ30〜40秒、100ステージでおよそ1時間。
- ステージ100のボスを倒すと GAME CLEAR、止めずに ∞ MODE へ。加速が強まり、性能が追いつかなくなったら終わり。
- 競うのは**到達メートル**（タイムアタックではない）。
- 途中で抜けられる。自動で保存し、戻ったら 3・2・1 のカウントダウンから再開。放置では進まない。

## 強さの流れ（序盤つらい → 中盤楽しい → 終盤苦しい）
- 最初は **1秒に1発・1列・1人・威力1**。魚も少なめだが、ぎりぎり。
- 連射・段数・仲間の上限は**ステージが進むと少しずつ開く**（ステージ70前後で全開）。1枚のゲートで +3 まで。
- 終盤は、深いマイナスゲートと速さで苦しくなる。
- 初回はすぐ負けてよい（コインを貯めて武器を手に入れ、遠くへ行けるようになる）。

## コイン・装備・ガチャ
- 旅が終わったら、**進んだ距離をコインに換算**（10m で1コイン、クリアしたステージ1つで25コイン）。
- 毎回の出発準備（1回だけの強化）は**なし**。代わりに、**装備（武器）とスキンをガチャで手に入れ、ずっと使える**。
- **武器ガチャ**（100コイン）：武器で撃ち方と最初の 連射・段数・威力 が決まる。同じ武器が出たらレベルアップ（威力×1.5、最大Lv5）。最大なら半額返却。
  - N：豆鉄砲（初期）/ ツイン / ファン　R：ラピッド / バウンサー / ウェーブ　SR：ショットガン / ホーミング / ビームキャノン　SSR：トライデント / ジョーズ
- **スキンガチャ**（60コイン）：見た目だけ（ワニの色）。10種類。持っていれば半額返却。
- 出る確率：N 60% / R 28% / SR 10% / SSR 2%。
- タイトルの「装備」で武器とスキンを選ぶ。

- 出発前の「出発準備」で、コインを使って**次の1回だけの強化**を買う：連射+1 / 段数+1 / 威力×2 / 仲間+1 / 満腹+3 / ライフ+1。
- 旅が終わるとリセット。タイムアタックではなく、コインで強くして遠くへ行く。

## 見た目・負荷
- 弾の本数と弾速は、スマホが熱くならない所まで。見た目の弾数に上限を設け、超えた分は1発の重みに乗せる。
- 軽量モード：重い端末では自動で提案・切替。タイトルで手動切替もできる。

## チュートリアル・遊び方
- 初めてスタートした時だけ、1つずつ実際にやって進むチュートリアル（移動 → 食べる → ゲートを撃つ → 届いて確定 → アイテムを壊す → まとめ）。スキップ可。
- チュートリアル中は飢えず、当たってもライフが減らない。ゲートは早めに届く。
- タイトルの「遊び方」でいつでも説明を読める。

## 起動・流用
- 起動画面は `infinity` と同じ流れ（ロゴ → クレジット → 注意事項）。アイコンだけ差し替え。
- **セーブスロットはなし**（セーブは1つ）。
- PWA・（今後）ランキングは `infinity` から流用してよい。

## 開発用
- `?bot`（自動操縦）・`?ts=10`（倍速）・`?clear=600`（100% までの秒数）は localhost でだけ効く。

## 公開
- `game/gate/` の更新は、確認なしで PR を作って main にマージ（公開）してよい。戻す指示があれば戻す。
