# GATE VADER 仕様メモ

決まったことをここに残す。実装はこの内容に合わせる。変えるときはここも直す。

## 名前・表記
- 名前は **GATE VADER**（英語表記で統一）。フォルダは `game/gate/`。
- マスコットはワニ。敵はインベーダー型のワニ、自機は緑のワニ。

## 画面（縦）
- 左半分＝**敵ワニの大群**（小さく・大量に。倒している感を出す）。右半分＝**迫ってくるゲートとアイテム**。
- 自機は下の中央に据え置き。触った横位置に狙いを向ける。段数が増えるほど弾の扇が広がる。
- 横画面（未実装）：縦画面を倒した形。対比は上下、進行は左か右。

## ゲート（右）
- 上からこちらへ迫ってくる。**撃つと数値が良い方向に動く**（マイナスも撃ち続ければプラスに転じる）。
- **自機に届いた瞬間に効果が確定**。対象は DMG（ダメージ）・LINE（段数）・CREW（撃つ人数）。
- 種類：＋ / − / × / ÷。未実装：武器変更（撃ち方が変わる・単発ビームなど）、ボーナスコイン。
- 表示と実際にかかる値は必ず一致させる（LINE・CREW は整数で効く）。

## アイテム（右）
- CREW / HEAL / POWER（未実装：強い助っ人）。**壊さないと手に入らない**。壊せずに届くとハート-1。

## 敵（左）
- モブにHPはない（一撃で倒れる）。強い弾は何体も貫く（上限あり）。
- 1体でも最下段に届いたらハート-1。直後は少し無敵。累計のカウントは持たない。
- 中ボス・大ボスだけHPを持ち、HPバーは頭の上。ボス戦中は進行バーがボスとモブの片付き具合で進む。

## 進行・エンドレス
- 加速はゆるやか。100% までおよそ50分（`CLEAR_SEC` で調整）。12.5% ごとにボス（4・8番目は大ボス）。
- 100% で GAME CLEAR を出しても止めず ∞ MODE へ。加速が強まり、性能が追いつかなくなったら終わり。
- 競うのは**到達メートル**（タイムアタックではない）。
- 途中で抜けられる。自動で保存し、戻ったら 3・2・1 のカウントダウンから再開。放置では進まない。

## 転生（未実装）
- 出発前に何を買うかで初期グレードを上げる。戻ったらリセット。旅の途中で稼いだコインで次の出発を強くする。

## 見た目・負荷
- 弾の本数と弾速は、スマホが熱くならない所まで。見た目の弾数に上限を設け、超えた分は1発の重みに乗せる。
- 軽量モード：重い端末では自動で提案・切替。タイトルで手動切替もできる。

## 起動・流用
- 起動画面は `infinity` と同じ流れ（ロゴ → クレジット → 注意事項 → スロット選択）。アイコンだけ差し替え。
- PWA・スロット・（今後）ランキングは `infinity` から流用してよい。

## 開発用
- `?bot`（自動操縦）・`?ts=10`（倍速）・`?clear=600`（100% までの秒数）は localhost でだけ効く。

## 公開
- `game/gate/` の更新は、確認なしで PR を作って main にマージ（公開）してよい。戻す指示があれば戻す。
