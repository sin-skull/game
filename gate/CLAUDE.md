# GATE VADER（game/gate）で作業するときの決まり

## いちばん大事：墨絵の世界観は絶対に崩さない
- 見た目はすべて **墨絵（墨と墨汁で描いた絵）＋ 和紙 ＋ 巻物（掛軸・絵巻）** の世界。これはオーナーが決めた、変えてはいけない方針。
- 色は **墨・うす墨・朱・藍** だけ。ネオン・グラデーションの派手な色・ピクセル絵・デフォルメの強いアニメ調・3D風は使わない。
- 絵は `ink.js` のように、筆のかすれ・墨のにじみのある線で描く。新しいキャラ・敵・アイテム・画面・UI・アイコン・イベントも、必ずこの世界観で作る。
- 背景は和紙。枠は掛軸（上下の軸）や絵巻（横長・右から左へ読む）に見立てる。
- 文字は筆の書体（Yuji Boku / Yuji Syuku）。英字・数字は読みやすさのため楷書寄りか明朝。
- 子ども向けにしない（対象は十代〜大人）。
- 日本の歴史・文化を誤解させない表現の決まりは `DESIGN.md` の「日本の文化を誤解させないための決まり」に従う。

## そのほか

- `game/gate/` の更新は、確認なしで PR を作って main にマージ（公開）してよい。
